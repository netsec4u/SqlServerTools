# Update-SmoSqlLoginPassword

## SYNOPSIS

Update SQL login password.

## SYNTAX

### __AllParameterSets

```
Update-SmoSqlLoginPassword
  -ServerInstance <string>
  -LoginName <string>
  -Password <securestring>
  -NewPassword <securestring>
  [-WhatIf]
  [-Confirm]
  [<CommonParameters>]
```

## ALIASES

This cmdlet has the following aliases:
  None

## DESCRIPTION

Update SQL login password.

## EXAMPLES

### Example 1

```powershell
Update-SmoSqlLoginPassword -ServerInstance MyServer -LoginName DBUser -Password $(Read-Host "Enter current password" -AsSecureString) -NewPassword $(Read-Host "Enter new password" -AsSecureString)
```

Updates the password for the specified SQL login.
