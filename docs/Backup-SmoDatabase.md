# Backup-SmoDatabase

## SYNOPSIS

Backup an sql database to local or remote disk.

## SYNTAX

### DatabaseName (Default)

```
Backup-SmoDatabase
  -ServerInstance <string>
  -DatabaseName <string>
  -BackupType <BackupSetType>
  -BackupFile <string[]>
  [-BackupSetDescription <string>]
  [-BackupSetName <string>]
  [-MediaDescription <string>]
  [-MediaName <string>]
  [-FileGroup <string[]>]
  [-LogicalFile <string[]>]
  [-BlockSize <int>]
  [-BufferCount <int>]
  [-MaxTransferSize <int>]
  [-Checksum]
  [-BackupCompression <BackupCompressionOptions>]
  [-CopyOnly]
  [-RetainDays <int>]
  [-TailLog]
  [-ScriptBackup]
  [-WhatIf]
  [-Confirm]
```

### DatabaseObject

```
Backup-SmoDatabase
  -DatabaseObject <Database>
  -BackupType <BackupSetType>
  -BackupFile <string[]>
  [-BackupSetDescription <string>]
  [-BackupSetName <string>]
  [-MediaDescription <string>]
  [-MediaName <string>]
  [-FileGroup <string[]>]
  [-LogicalFile <string[]>]
  [-BlockSize <int>]
  [-BufferCount <int>]
  [-MaxTransferSize <int>]
  [-Checksum]
  [-BackupCompression <BackupCompressionOptions>]
  [-CopyOnly]
  [-RetainDays <int>]
  [-TailLog]
  [-ScriptBackup]
  [-WhatIf]
  [-Confirm]
```

## ALIASES

This cmdlet has the following aliases:
  None

## DESCRIPTION

Perform a backup of the specified database to a local or network disk.

## EXAMPLES

### Example 1

```powershell
Backup-SmoDatabase -ServerInstance MyServer -DatabaseName AdventureWorks -BackupType Database -BackupFile 'C:\Backups\AdventureWorks.bak'
```

Backups AdventureWorks database to specified path.

### Example 2

```powershell
$DatabaseObject = Get-SmoDatabaseObject -ServerInstance MyServer -DatabaseName AdventureWorks
Backup-SmoDatabase -DatabaseObject $DatabaseObject -BackupType Database -BackupFile 'C:\Backups\AdventureWorks.bak'
```

Backups AdventureWorks database to specified path using database object.
